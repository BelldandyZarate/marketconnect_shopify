# MarketConnect Shopify — Aplicación Shopify con Node y React

**MarketConnect Shopify** es una aplicación web desarrollada sobre el ecosistema de **Shopify**, utilizando como base el template de Shopify para **Node y React**. El proyecto está orientado al desarrollo de aplicaciones personalizadas para tiendas Shopify, permitiendo integrar funcionalidades propias con la administración y operación de una tienda en línea.

La aplicación implementa una arquitectura frontend y backend que permite interactuar con los servicios de Shopify mediante sus APIs, gestionar la autenticación de usuarios y trabajar con información de la tienda de forma segura.

El proyecto también incorpora herramientas propias del ecosistema Shopify para facilitar el desarrollo de interfaces, autenticación, comunicación con la plataforma y gestión de eventos.

### 🛠️ Tecnologías y herramientas

* **Backend:** Node.js, Express
* **Frontend:** React, Vite
* **Lenguaje:** JavaScript / TypeScript
* **Routing:** React Router
* **API:** Shopify GraphQL Admin API y REST Admin API
* **Autenticación:** OAuth
* **Shopify:** Shopify CLI, App Bridge, Polaris y Webhooks
* **Gestión de datos:** Prisma / SQLite
* **Internacionalización:** i18next, react-i18next
* **Contenedores:** Docker
* **Control de versiones:** Git y GitHub

### 📌 Principales funcionalidades

* Integración de una aplicación personalizada con Shopify.
* Autenticación mediante **OAuth**.
* Consulta y modificación de información de la tienda mediante **GraphQL Admin API**.
* Integración con **REST Admin API**.
* Comunicación autenticada entre el frontend y las APIs de Shopify.
* Implementación de interfaces utilizando **Polaris**.
* Integración de **Shopify App Bridge**.
* Gestión de eventos mediante **Webhooks**.
* Navegación mediante React Router.
* Soporte para internacionalización mediante i18next.
* Gestión de sesiones y almacenamiento mediante SQLite.
* Configuración para desarrollo y despliegue mediante Shopify CLI y Docker.

### 🎯 Objetivo del proyecto

Desarrollar una aplicación web integrada con Shopify que permita ampliar las capacidades de una tienda mediante funcionalidades personalizadas, aplicando conocimientos de **desarrollo Full Stack, integración de APIs, autenticación, gestión de datos, desarrollo frontend y backend y despliegue de aplicaciones web**.

### 💻 Tipo de proyecto

**Proyecto de desarrollo web e integración con Shopify**, enfocado en la creación de aplicaciones personalizadas para comercio electrónico utilizando tecnologías modernas de desarrollo Full Stack.
